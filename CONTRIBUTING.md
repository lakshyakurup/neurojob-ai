# Contributing to NeuroJob AI

Thank you for considering contributing to NeuroJob AI!

## How to Contribute
1. **Fork the repository** on GitHub.
2. **Clone your fork** locally (`git clone https://github.com/lakshyakurup/neurojob-ai.git`).
3. **Create a branch** for your feature or fix (`git checkout -b feature/amazing-feature`).
4. **Commit your changes** (`git commit -m 'feat: add amazing feature'`).
5. **Push to your branch** (`git push origin feature/amazing-feature`).
6. **Open a Pull Request** against the `main` branch.

## Code Style & Standards
* Keep code clean, modular, and well-typed with TypeScript.
* Ensure all tests and linting pass before submitting.
